# 실험 여정

각 단계는 당시의 가설과 공개 리더보드 결과를 구분해 기록한다. 전체 제출값은 [공식 제출 표](experiments.md)에 있다.

| 시기 (2026 KST) | 가설과 실험 | 공식 관측 | 결정과 다음 방향 |
|---|---|---|---|
| 8/29–9/3 | 제공된 기준 모델을 안전하게 실행하고 음성/음악 구간 풀링을 바꿈 | sub01 0.69091 → sub02 0.69725; 단순 FILE 경로는 불안정 | 성분별 신호와 FILE 결합을 분리해 검증 |
| 9/4–9/7 | NII 음성 점수와 학습된 FILE 결합, 채널 변형을 추가 | sub21 0.76558, sub24 0.77645, sub25 0.78468 | 그룹 단위 분할과 채널 견고성을 유지하며 FILE 확대 |
| 9/8–9/13 | 음악 전용 모델, 시간 정보, 추가 특징과 learned FILE을 평가 | sub39 0.80203; Deezer 분기 sub40 0.78814 | 한 도메인의 로컬 이득이 전체 숨겨진 분포에 불리할 수 있음을 확인 |
| 9/14–9/20 | MUSIC17, FILE floor, 추가 성분 검출기를 누적 검증 | sub44 0.80550, sub55 0.81373; 여러 후보는 하락 또는 동률 | 작은 패널 향상을 공식 업로드로 검증하고 실패 분기를 멈춤 |

| 9/29 | 실제 음성·음악 데이터를 추가하면 전이할지 2-fold와 전량 학습으로 확인 | sub106 0.84393, sub111 0.83944, sub112 0.84255 | 로컬 2-fold 이득에도 공식 하락. sub102r3 유지, 54위 마감 |

9/27의 분석은 CPS가 이미 약 0.989라서 완벽한 존재 검출조차 총점에 약 0.001만 더할 수 있음을 보여 주었다. 15위까지는 ADS 약 0.04 상승이 필요했고, FILE 한 헤드만으로 메우려면 EER을 약 8%p 줄여야 했다. 그래서 여러 작은 가중치 조정보다 원본 혼합물에 대한 백본 미세조정을 우선했다.

가장 중요한 교훈은 검증 분포였다. 렌더링 혼합물의 홀드아웃은 모델 학습 목적과 매우 가까워 r2의 실제 상승을 과장했다. 더 현실적인 패널은 첫 상승의 방향은 맞혔지만 r3 상승을 과소평가했고, 실데이터 추가 학습의 유효성을 과대평가했다. 2-fold의 그룹 분리는 누출을 줄였지만, 패널 자체가 숨겨진 테스트를 대표한다는 보장은 주지 못했다.
