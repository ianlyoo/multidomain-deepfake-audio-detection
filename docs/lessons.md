# 다음 실험을 위한 교훈

1. **학습 데이터의 구성은 결합 계수보다 큰 변수였다.** 약한 FILE/VOICE 패널 이득을 쌓은 sub100은 sub97b보다 0.00226 낮았다. 음성과 음악이 섞인 파일을 직접 렌더링해 백본을 학습하자 sub100 대비 0.01065 올랐다.
2. **파일 단위 라벨을 창 단위로 무작정 복제하지 않았다.** 렌더 배치와 성분 구간을 따라 4초 창의 fake/present 라벨을 만들고 애매한 창은 손실에서 마스킹했다. 부분 합성 파일에서 특히 중요했다.
3. **검증 패널은 선택 근거이지 숨겨진 평가의 대체물이 아니다.** 혼합물 홀드아웃은 r2의 상승을 크게 과장했고, 실데이터 2-fold의 약 1.7%p EER 개선은 공식 점수 개선으로 이어지지 않았다.
4. **성분별 변경과 floor 순서를 고정해 원인을 추적했다.** FILE 결합 전에 새 신호를 넣는지, VOICE/MUSIC 공개 출력에만 넣는지에 따라 효과가 달랐다. 다른 출력이 바뀌지 않음을 검증해야 점수 차이를 특정 헤드에 귀속할 수 있다.
5. **순위 목표는 필요한 EER 변화로 환산한다.** 존재 AUC가 포화된 뒤에는 CPS 개선으로 격차를 좁힐 수 없었다. 마지막에는 구조적인 백본 변경을 우선했다.
6. **실험 기록과 재현 자산을 데이터·모델과 분리한다.** 제출 점수, 실패, 코드, 설정은 공개할 수 있지만 외부 오디오와 가중치는 원천별 권리가 다르다. 재현에는 원본 라이선스와 모델 버전을 별도 확인해야 한다.
